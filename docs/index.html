FAQ

Useful things to know.

What is WP Lab?

WP Lab is a local WordPress and WooCommerce development environment for Linux that manages isolated Docker sandboxes from one desktop interface.

Can WP Lab run multiple local WordPress sites?

Yes. Every instance has separate WordPress data, database data, ports, PHP settings, logs, and a Mailpit inbox.

Can I test themes and plugins on different PHP versions?

Yes. WP Lab currently supports PHP 8.2, 8.3, and 8.4 while preserving the sandbox's WordPress data.

Can I use WP Lab for WooCommerce development?

Yes. WP Lab includes WooCommerce testing helpers, demo data, local email capture, test shipping, and dummy payment outcomes.

Does it work on Ubuntu and Linux Mint?

That is the environment WP Lab is currently focused on. It uses Docker Engine and Docker Compose underneath.

Can I share a local site with a client?

Yes. WP Lab can create a temporary HTTPS preview using Cloudflare Tunnel and stop it again from the app.
